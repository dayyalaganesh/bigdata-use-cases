17. Consider the following class hierarchy utilizing cooperative super() calls:
class A:
    def show(self):
        return "A"
class B(A):
    def show(self):
        return "B" + super().show()
class C(A):
    def show(self):
        return "C" + super().show()
class D(B, C):
    def show(self):
        return "D" + super().show()
What is the output of print(D().show())?
       A. DBA
       B. DBCA
       C. DCA
       D. DBAC
      ANSWER: B
