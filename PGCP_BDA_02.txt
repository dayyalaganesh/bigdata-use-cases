17. Consider the following class using a property setter with validation:
class Wallet:
    def __init__(self, balance):
        self.balance = balance
    @property
    def balance(self):
        return self.__balance
    @balance.setter
    def balance(self, amount):
        if amount < 0:
            raise ValueError("Negative balance")
        self.__balance = amount
w = Wallet(50)
try:
    w.balance -= 100
except ValueError:
    w.balance += 20
print(w.balance)
What is the output?
       A. 70
       B. -30
       C. 20
       D. -50
      ANSWER: A
